Tentang Aplikasi

Aplikasi Keuangan Pribadi ini dirancang untuk memudahkan Anda memantau arus kas masuk dan keluar secara terorganisir.

Fitur Utama:

- Manajemen Input Data (Pemasukan & Pengeluaran) real-time.
- Fitur Pencarian & Multi-Filter berdasarkan kriteria tertentu.
- Kalkulasi Otomatis Grafik Lingkaran (Pie Chart) persentase alokasi keuangan.
- Skalabilitas Filter Riwayat Rekapitulasi Fleksibel.

Sistem Terintegrasi Cloud Database Firebase Realtime.
