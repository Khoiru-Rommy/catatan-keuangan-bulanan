Tentang Dashboard

Pembaruan terbaru mengubah antarmuka menjadi standar Aplikasi Web FinTech profesional.

  • Navigasi Kiri: Layout menu vertikal permanen di bagian kiri layar untuk visual luas.
  • Fitur Grafik Khusus: Kini memiliki tab tersendiri untuk visualisasi data penuh.
  • Filter Harian Spesifik: Sekarang Anda bisa menyaring data secara presisi per hari pada menu Riwayat, Rekap, dan Grafik.
  • Database tetap aman terintegrasi penuh menggunakan Firebase Cloud Real-time.
